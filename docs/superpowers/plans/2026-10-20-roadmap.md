# PoultryOS Web — Master Roadmap (2026-10-20)

**Goal:** build the PoultryOS web app described in `BUILD-BRIEF.md`, with the UI of `demo/index.html`, plus the owner's additional requirements (R1–R10 below). Web comes first; Android (Capacitor) is the final phase.

**How to use this file:** the project is too large for one plan, so each phase below gets its own bite-sized plan in this folder, written just before that phase starts. Only Phase 1 is written in detail (`2026-10-20-phase-01-foundation.md`). Every phase must leave the app deployable and tested.

**Sources of truth (read before any phase):**
- `BUILD-BRIEF.md`: stack, routes, screens, forms, offline, acceptance tests, non-negotiables
- `demo/index.html`: the UI. Same screens, classes, copy, flows. Ported functions keep their names: `batchKpi`, `tenantKpi`, `costPerEgg`, `ageing`, `attMonth`, `lineChart`, `barChart`, `spark`, `form`, and the `ACT` keys.
- `supabase/migrations/0001,0002`: extend with new migrations only, never redesign
- `supabase/functions/*`: reuse; `provision-tenant` is the account-creation step after approval
- `scripts/gen_seed.py`: single source of demo data. If the schema changes, update it and regenerate `seed.sql` + `demo/data.json`
- `android-xml/res/values*/strings.xml`: Telugu strings for i18n

## Research findings for R6, R8, R10 (2026-10-20)

Labels: [V] = checked against a primary source; [B] = believed, make it configurable.

**Name check:** poultryos.com is already a live Indian contract-broiler software product. **Check the trademark and domain before launch.**

**Application form (M = mandatory)**
- **Identity:** legal name + entity type M; PAN M; GSTIN optional; Udyam optional.
- **Licences:** FSSAI if selling or packing eggs (registration up to ₹12 L turnover, licence above) [V]. Pollution Control Board CTE/CTO, M above 5,000 birds (CPCB, from 1 Jan 2023) [V]. Trade licence/NOC M [B].
- **Bank and ID:** bank account + IFSC + cancelled cheque M; masked Aadhaar of the signatory M.
- **Contact:** owner name M; mobile (OTP-verified) M; alternate phone; email (optional, many rural owners lack one); WhatsApp (defaults to the mobile); language M.
- **Each site:** address, village/mandal/district/state/PIN M; GPS M (drives the bird-flu radius and weather alerts); land area (acres) M; owned/leased.
- **Each shed:** name; length × width; open-sided / environment-controlled (EC) / semi-EC; floor (deep litter / cage / slatted); design capacity; max birds. All M.
- **Layer:** cage system, tiers, birds per cage M.
- **Hatchery:** setter/hatcher count + capacity, single- or multi-stage, eggs set per week M.
- **Operations:** farm types, current birds, breed, model (independent / integrator contract / own integration), monthly volume M.
- **Optional:** labour count by role, power (grid/solar/generator kVA), water source, biosecurity, existing records.
- **Consent** M.

**KPIs**
- **Broiler:**
  - FCR = feed ÷ live weight. Cobb 500 at 42 days: about 3.05–3.5 kg live weight, FCR about 1.53–1.59 [V]. Indian field FCR is about 1.85 [V].
  - EPEF = livability% × kg × 100 ÷ (age × FCR) [V].
  - Water:feed ratio about 1.6–1.8 [V].
  - Brooding temperature 30 °C at day 0 [V].
  - Integrator settlement: growing charge per kg with FCR and mortality slabs.
- **Layer (Hy-Line W-80):**
  - peak hen-day 94–98%; hen-housed eggs about 367–382 to 80 weeks
  - feed per dozen 1.39–1.44 kg; uniformity > 85–90% [V]
  - BV-300 breeder peak 95% [V]
  - cracked eggs about 1–3% [B]
- **Hatchery (Cobb):**
  - fertility 91–96%; hatchability 82–86%; hatch of fertile about 89–90% [V]
  - storage: 18–19 °C for 1–6 days, 15–17 °C beyond [V]
  - eggshell temperature 37.7–38 °C, setter RH 47–52%, transfer day 18–19 [V]
  - chick grades A/B/cull

**Alerts** (default thresholds, overridable per tenant):

| Alert | Trigger |
|---|---|
| Mortality spike | > 1.8× the 7-day baseline (demo rule) or > 0.1–0.2%/day after week 1 [B] |
| Temperature/RH | Outside the age setpoint [V] |
| Water drop | > 10% vs yesterday [B] |
| Feed intake drop | Below standard or yesterday |
| Hen-day drop | 2–3 points below the curve |
| Weight | > 5–10% below standard, or uniformity < 85% |
| Vaccination due | Schedule × batch age |
| Low stock | Days of cover below N |
| Money | Payments due / overdue |
| Equipment | Ticket raised, sensor offline, missing daily log |
| Hatchery | Setter outside band; egg storage > 7 days |
| Heat stress | THI = (1.8T+32) − (0.55−0.0055·RH)(1.8T−26.8); cut-offs configurable |
| Bird flu nearby | Within 1 km / 10 km of farm GPS (DAHD AI Action Plan 2021) [V] |
| Market rate move | Daily change beyond ±X% |

**Labour daily entry**
- **Broiler:** deaths and culls with reason, feed bags, water meter, min/max temperature + RH, litter condition, medicine/vaccine, sample weights, lifting, photos.
- **Layer:** eggs per row, split good / cracked / dirty / small; trays; deaths; feed; water; light hours; temperature; dispatch.
- **Hatchery** (per shift): eggs received per flock, rejects, egg-store temperature/RH, per-machine temperature/RH, turning check, candling results, transfer, chicks A/B/cull, residue, chick vaccination, dispatch, faults and power cuts.
